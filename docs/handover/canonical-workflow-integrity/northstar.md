# North Star

VibeComfy lets people and agents change workflows confidently without losing their work.

N1. Small edits preserve unrelated authored graph content and stable identity.
N2. Unfinished work is legitimate: saving and canvas editing do not require execution readiness.
N3. Lossy transformations are explicit and narrowly justified; loadability or a matching name is not proof of preservation.
N4. Each correctness rule has one owner; useful authoring interfaces, projections, and execution transports may differ.
N5. Publication and execution have clear provenance and revision identity; newer human work is protected.
N6. Prefer existing mechanisms and bounded fixes. Avoid universal frameworks, speculative abstraction, duplicated gates, and cleanup justified only by fewer code paths.

Aligned progress makes ordinary edits predictable and failures explainable while keeping draft work easy.
