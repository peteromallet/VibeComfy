## Batch summary

Dominant failure classes in this r6 batch: **judge_or_harness_bug (2/6 — d93baf, img2vid-gen)** and **budget_or_retry_exhaustion (3/6 — crops, img2obj, img2vid-llm)**, with grounding_or_evidence (1/6 — gaussian). Two systemic defects drive all six. First, the response-boundary projection drops the inner executor's accepted Δ: in d93baf and img2vid-gen the edit verifiably landed in the retained IR (Δ=d1 minted, session `two_step_workflow.json` updated) while the outer response still stamps `graph_unchanged: true` / `no_candidate_reason: route_not_applyable` / `candidate: null`, so `final.ui.json` is written equal to the original and the judge — grading the only surface it can see — reports an empty Δ. This is a live philosophy-#2 (two authorities) violation: the edit door and the judge door diverge. Second, offline schema coverage is missing for the custom classes these scenarios target (ReActorFaceSwap, Image Remove Background Rembg (mtb), StringFunction|pysssss, HWMInference, String Replace (mtb)), which forces the model to guess widget/port names; because a wrong guess is a semantic rejection that burns the single per-message replacement window (`two_step.py:298` `max_replacements=1`), three runs died on `replacement_attempts: used 1 of limit 1` or a 64-continuation research loop (img2obj). The gaussian scenario is the residual grounding-gate conflict: causal claims can never be cited for an unschematized node pack, and the fail-closed path hands the judge an internal guard string instead of the agent's substantive answer. (At the r5 run commit `bcf92497`, all six graphs additionally ingested to 0 nodes in the edit session — reproduced — which blocked every r5 edit; that layer is fixed post-run, as the r6 Δ=d1 landings prove.)

**Single highest-leverage fix:** propagate the inner accepted Δ and the retained-IR UI projection into the outer response contract — when `report.executor.execute.accepted_delta_ids` is non-empty, the outer builder must not stamp `graph_unchanged: true`/`route_not_applyable`, must populate top-level `accepted_delta_ids`, and `final.ui.json` must be written from the retained IR's emit door (so `artifacts.py:433`'s consistency guard can see the Δ). That single change flips d93baf and img2vid-gen immediately and makes the measurement honest for every edit scenario. Secondary, high-leverage: make the per-message replacement window retry-safe for unknown-field/unknown-port errors (or surface schema-derived port names in the render for unschematized classes) so a single name guess cannot kill a run, and stop emitting the internal grounding-violation string as the user-facing reply (surface the agent's last substantive answer with an explicit ungrounded caveat).
