## 3. Clone lifecycle

**On-demand clones**

- Default root: `VIBECOMFY_SCHEMA_SANDBOX` or `~/.cache/vibecomfy/schema-sandbox` (`on_demand.py:32–34`).
- Target: `sandbox_root / slug` where slug is `ref.slug` or `ref.registry_id` or URL tail (`211–213`).
- If dir exists: `os.utime` (LRU bump) and reuse — **no fetch, no install** (`214–220`).
- Else: `_enforce_cap()` then `git clone --depth 1` with `timeout=self.clone_timeout` (default 120) (`221–232`). Failure → `None`.
- LRU: dirs sorted by **mtime oldest-first**; evict while `total_packs > max_packs` **or** `total_bytes > max_bytes` (`234–264`). Defaults: **64 packs**, **2 GiB** (`50–51`); env `VIBECOMFY_SCHEMA_SANDBOX_MAX_PACKS` / `_MAX_BYTES`.
- In-process memo: `self._cache[class_type] = schema | None` (`93, 99–103`) — negatives cached.
- **Nothing is pip-installed** into the user env or a venv. Clone is source only. Eviction is `shutil.rmtree`.

## 4. How manifests are referenced today (gated classes, pack names)

`schemas` CLI does **not** read any manifest.

Harness comparison manifests (`tests/live_agentic_harness/threaded_comparison_manifest_final50.json:1–12`, default `threaded_comparison_manifest.json` at `compare_pipeline_modes.py:31`) have:

```json
{ "schema_version": 1, "modes": [...], "entries": [ { "id", "descriptor_sha256", "source_workflow_sha256", "locked_input_sha256" } ] }
```

**No class types, no pack names.** `--manifest` is on the comparator (`compare_pipeline_modes.py:1745`), not on `vibecomfy schemas`.

Gated class/pack coupling is hardcoded in `scenario_obligations.py`:

- `SCHEMA_EVIDENCE_REQUIREMENTS[scenario_id]`: `class_type`, `pack`, `source: "authoritative_object_info"`, port lists (`56–93`).
- `_GATED_CLASS_RE`: IndexTTS, LayerMask, Audio*, Inspire, easy forLoop, llama_cpp, ACN_… (`121–127`).
- `UNPROVEN_PROVIDER_CLASSES[scenario_id]`: gated classes **without** live capture (`146+`), treated as declaration/preflight **violations** (`933–978`).

Pack names for extraction come from `CustomNodePack.name` in `get_known_node_packs()` (`_defs.py:16–22, 449–457`), not from the comparison manifest.

Unrelated `--manifest`: `commands/reorganise.py:626`.
